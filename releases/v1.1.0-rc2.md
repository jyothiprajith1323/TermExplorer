## Overview

TermExplorer V1.1.0-RC2 is the second release candidate towards the stable V1.1.0 milestone. This release delivers a major developer workstation upgrade: an advanced rope-backed code editor with syntax highlighting, an intelligent 4-layer completion engine, hardened WebAssembly plugin execution with memory bounds, POSIX atomic file safety, and Unicode/emoji rendering fidelity across the approved **25% File Explorer / 75% Preview** workstation layout.

---

## Key Highlights

- **Approved 25/75 Workstation Layout:** Default proportions optimized for modern wide monitors. The contextual preview panel occupies 75% of application width, with an optional 15% terminal drawer hidden by default (`show_terminal = false`).
- **Advanced Code Editor Engine:** Powered by `ropey` text rope architecture, supporting large files, character-safe indexing, visual block selections, bounded multi-step undo/redo, and search/replace.
- **4-Layer Autocomplete Engine:** Sub-millisecond completions combining in-buffer words (Layer 1), workspace symbol indexing (Layer 2), language snippet templates (Layer 3), and asynchronous LSP query integration (Layer 4).
- **WebAssembly Sandboxing:** Enforced 16 MiB linear memory ceilings via `wasmi::ResourceLimiter` and 5,000,000 instruction fuel quotas per guest execution call.
- **Data Durability:** Atomic file replacement with POSIX `sync_all()` guarantees on temporary files and parent directories prior to rename commits.
- **Unicode & Preview Ergonomics:** Clamped preview scrolling preventing runaway offsets, safe column slicing avoiding UTF-8 panics, and clean heading rendering without block glyph artifacts.

## Installation

### Standalone Pre-compiled Binary (Fastest)

```bash
# 1. Download release archive and SHA256 checksums
curl -LO https://github.com/jyothiprajith1323/TermExplorer/releases/download/v1.1.0-rc2/termexplorer-v1.1.0-rc2-x86_64-unknown-linux-gnu.tar.gz
curl -LO https://github.com/jyothiprajith1323/TermExplorer/releases/download/v1.1.0-rc2/SHA256SUMS

# 2. Verify SHA-256 integrity
sha256sum --ignore-missing -c SHA256SUMS

# 3. Extract and install
tar -xzf termexplorer-v1.1.0-rc2-x86_64-unknown-linux-gnu.tar.gz
mkdir -p ~/.local/bin
install -m 755 termexplorer-v1.1.0-rc2-x86_64-unknown-linux-gnu/termexplorer ~/.local/bin/termexplorer
```

### Build from Source via Cargo

```bash
cargo install --git https://github.com/jyothiprajith1323/TermExplorer.git --tag v1.1.0-rc2 --locked
```

## Upgrade Instructions

Existing configurations at `~/.config/termexplorer/config.toml` are automatically preserved and migrated. The new `[layout]` settings will inherit existing user preferences without overwriting custom keybindings, theme selections, or pinned bookmarks.
