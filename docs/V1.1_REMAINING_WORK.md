# TermExplorer V1.1.0 — Remaining Work & Roadmap

**Release Status:** Ready for Sign-Off & Release Candidate Tag  
**Milestone:** V1.1.0 Stabilization & Completion Engine  

---

## 1. Feature Completion Checklist

- [x] **Remove Static Workspace Sidebar from Default Interface**
  - [x] Config default updated (`show_sidebar = false`).
  - [x] Layout algorithm allocates 70% to File Explorer and 30% to Contextual Preview.
  - [x] Sidebar only renders if explicitly enabled by user and terminal width >= 110 columns.
  - [x] Pinned folders and recent directories accessible via `Ctrl+P` and path autocompletion.
- [x] **Bottom Terminal Default Restoration**
  - [x] Config default updated (`show_terminal = true`).
  - [x] Terminal session auto-started on application startup.
  - [x] Terminal default height set to ~25% (min 5 rows).
  - [x] `Alt+F6` / `Ctrl+Shift+T` 3-way toggle (Normal ~25% -> Maximized ~80% -> Hidden 0%).
  - [x] Keyboard focus cycling (`Tab` / `BackTab`) handles only visible panels (no invisible sidebar focus trap).
- [x] **Universal Resizing Shortcuts**
  - [x] `[` / `]` and `Ctrl+Left` / `Ctrl+Right`: Resize explorer/preview width percentage (15% - 65%).
  - [x] `{` / `}` and `Ctrl+Down` / `Ctrl+Up`: Resize bottom terminal height (5 - 40 rows).
  - [x] `F11` / `Z`: Fullscreen preview toggle (100% width).
- [x] **Intelligent Autocomplete & Suggestions Engine (`src/completion/`)**
  - [x] Layer 1: Local buffer words (< 20 ms).
  - [x] Layer 2: Workspace symbol indexer (< 100 ms) ignoring build/git directories.
  - [x] Layer 3: Snippet engine for Rust, Python, C, Java.
  - [x] Layer 4: Async non-blocking LSP hook with monotonic request cancellation.
  - [x] Explorer path completion with tilde expansion and directory trailing slash.
  - [x] Command Palette ranking with acronym matching and dynamic navigation.
  - [x] Completion latency telemetry benchmarks and assertions.
- [x] **Catppuccin Theme Ecosystem**
  - [x] Mocha, Macchiato, Frappé, Latte canonical palettes.
  - [x] Transparent background inheritance.
  - [x] Custom TOML theme loader.
- [x] **Icon Packs & Typography**
  - [x] Catppuccin, NerdFont, Unicode, Ascii, None icon packs.
  - [x] JetBrains Mono font detection and installer script.
- [x] **WASM Plugin Architecture**
  - [x] `wasmi` runtime, SHA-256 integrity checks, permission enforcement.
  - [x] Example plugins: `workspace-tools`, `file-inspector`.
- [x] **Comprehensive Testing & QA**
  - [x] Unit tests across all modules.
  - [x] Adversarial filesystem tests (symlinks, unicode, deleted preview, large dirs).
  - [x] Terminal throughput & edge cases (1 MB circular scrollback, ANSI translation).
  - [x] Editor edge cases (auto-pair, undo/redo consistency, cursor clamping).
  - [x] Visual UI tests with responsive breakpoints.
- [x] **Documentation & Website Updates**
  - [x] Complete technical documentation suite in `docs/`.
  - [x] Website updated with two-column layout, latency charts, plugins, themes, and fonts.

## 2. Post-V1.1 Future Roadmap (V1.2+ Preview)

1. **Native LSP Process Spawner:** Integrate `rust-analyzer` and `pyright` standard stdio language server subprocesses using the existing Layer 4 hook.
2. **Terminal Session Tabs:** Multi-tab shell sessions in bottom panel with separate PTY streams.
3. **Split Editor Panes:** Side-by-side file editing within the internal editor buffer.
4. **Git Interactive Rebase:** Interactive TUI tool for squash/fixup commits directly within the Git workbench.
