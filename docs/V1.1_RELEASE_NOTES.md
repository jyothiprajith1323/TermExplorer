# TermExplorer V1.1.0 Release Notes

**Release Date:** November 2026  
**Codename:** *Personalization, Themes & Extensibility*

---

## Highlights

TermExplorer V1.1.0 transforms TermExplorer into an extensible developer environment with theme ecosystems, icon customization, typography detection, and sandboxed WebAssembly plugins.

---

## Key Features

### 1. Canonical Catppuccin Theme Ecosystem
- Full 26-color canonical palette implemented across all four official flavors:
  - **Catppuccin Mocha:** Flagship soothing dark theme (new default).
  - **Catppuccin Macchiato:** Medium-contrast dark palette.
  - **Catppuccin Frappé:** Low-contrast muted dark palette.
  - **Catppuccin Latte:** Crisp daylight pastel light palette.
- **Design Tokens:** Strict separation of palette values, semantic UI tokens (`ThemeTokens`), and component styles.
- **Custom Themes Engine:** Drop `.toml` files into `~/.config/termexplorer/themes/` with automatic parsing, live preview, and validation fallbacks.

### 2. Multi-Mode Icon Engine
- Support for **5 distinct icon modes**:
  - `Catppuccin`: Nerd Font v3 glyphs with canonical Catppuccin color assignments.
  - `NerdFont`: Clean monochrome Nerd Font v3 icons.
  - `Unicode`: Cross-platform Unicode symbols and emoji fallbacks.
  - `Ascii`: Low-bandwidth bracketed tags (`[RS]`, `[DIR]`, `[FILE]`).
  - `None`: Minimalist mode without icon prefixes.
- Over 40+ programming language extensions, 15+ special config filenames (`Cargo.toml`, `package.json`, `Dockerfile`, etc.), and folder categories (`src/`, `tests/`, `docs/`, `target/`, `.git/`, `config/`, etc.).
- Custom associations via `~/.config/termexplorer/icons.toml`.

### 3. Typography & JetBrains Mono Support
- Automatic host inspection via `fontconfig` (`fc-list` and `fc-match`) to verify presence of `JetBrains Mono` and `JetBrainsMono Nerd Font Mono`.
- Guided setup instructions for Kitty, Alacritty, WezTerm, and GNOME Terminal.
- Safe, non-root user installation script for `~/.local/share/fonts/`.

### 4. Sandboxed WebAssembly Plugin System
- Lightweight, pure-Rust WebAssembly interpreter powered by `wasmi` (v0.36) and `sha2` (v0.10).
- Explicit capability permissions: `commands`, `workspace_actions`, `file_metadata`, `context_actions`, `preview_provider`, and `status_text`.
- Bounded instruction fuel limits (`5,000,000` steps) preventing infinite loops.
- Crash and panic isolation: guest traps never crash the host process.
- Two working reference plugins: `workspace-tools` and `file-inspector`.
- Status bar telemetry integration for active plugins.

### 5. Interactive Settings Studio & Command Palette Updates
- Live icon pack and theme switching with instant render update.
- Host font detection summary in Settings Studio section 2.
- Quick switch commands in Command Palette (`Ctrl+Shift+P` / `Space`).
