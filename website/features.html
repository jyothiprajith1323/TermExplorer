Comprehensive Feature Breakdown

Engineered for Precision & Flow

Explore the deep capabilities of TermExplorer: from universal multi-format file inspection to dual-pane file management and real-time PTY terminal emulation.

1. Universal Multi-Format Preview Engine

TermExplorer includes a dedicated src/preview/ subsystem with 4 active inspector tabs: [Preview], [Information], [Hex], and [Actions]. File type detection is powered by a magic-bytes detector that inspects file signatures before falling back to extensions.

2. Dual-Pane File Management

Dual-Pane Split (F7)

Split your file explorer into primary and secondary panes side-by-side. Navigate both independently and transfer files across panes with single keystrokes (c for copy, m for move).

FreeDesktop Trash (d)

Accidental deletions are a thing of the past. TermExplorer prioritizes gio trash and trash-put to move files safely to your OS desktop trash before asking for permanent removal (D).

Bookmarks & Workspaces

Pin frequently used folders (p) or jump to your home directory, root, or project workspaces (b) via the unified sidebar.

3. Interactive Settings Studio (F10)

Configure every aspect of your developer environment through a dedicated full-screen TUI modal covering 15 distinct sections:

15 Config Sections

General, Appearance, Keybindings, Explorer, Preview, Editor, Terminal, System Monitor, Git, Bookmarks, Profiles, Performance, Plugins, Advanced, and About.

Keybinding Conflict Detection

Interactive key action registry with scope isolation (Global, Explorer, Editor, Terminal, Preview, Git). Automatically flags colliding keystrokes before they cause issues.

6 Built-in Profiles

Switch instantly between Default, Developer, Minimal, TerminalPowerUser, EditorFocus, and Monitoring with full persistence to config.toml.

4. Developer Command Center

Command Palette (Ctrl+Shift+P)

Fuzzy-search across all internal commands, toggle views, jump to bookmarks, reload configuration, or launch workspace tasks with a modern floating modal.

Git Integration (g)

Inspect repository status, branches, staged vs. unstaged files, and recent commit history without switching windows. Stage files with s directly from the overlay.

Smart Workspace Detection

Automatically detects Cargo (Rust), Python, Node.js, Go, C/C++, Java, and Makefile projects. Provides quick actions to build, test, and run your project.
