1. Universal Multi-Format Preview Engine

TermExplorer includes a dedicated preview subsystem with 4 active inspector tabs: [Preview], [Information], [Hex], and [Actions]. File type detection is powered by magic bytes detection before falling back to extensions.

2. The Two-Column Developer Workstation

Standardized layout architecture designed to maximize horizontal screen efficiency without wasting room on permanent sidebars.

🗂️

Standardized 25/75 Ratio

The Explorer occupies 25% width while the Contextual Preview occupies 75% width. Press Ctrl+Right / Ctrl+Left (or Alt+] / Alt+[) to expand or shrink proportions on the fly with 5% increments (up to 85% width).

󰕰

Dual-Pane Explorer (F7)

Split the file explorer into primary and secondary panes side-by-side. Navigate both independently and transfer files across panes with single keystrokes (c/y copy, x cut, p/v paste).

🗑️

FreeDesktop Trash Integration (d / Del)

Accidental deletions are eliminated. TermExplorer prioritizes gio trash and trash-put to move files safely to your OS desktop trash with explicit confirmation before permanent deletion (D).

⚙️

3. Interactive Settings Studio (F10 / Ctrl+,)

Configure every aspect of your developer workstation through a dedicated modal covering 14 customizable categories:

🎨

Theme & Appearance

Live switching across all 4 official Catppuccin flavors (Mocha, Macchiato, Frappé, Latte) plus 8 community themes, with transparent terminal inheritance and truecolor support.

󰋖

Keybinding Conflict Detection

Interactive key action registry with scope isolation (Global, Explorer, Editor, Terminal, Preview, Git). Automatically flags colliding keystrokes before they cause issues.

💾

Profile Management

Switch instantly between Default, Developer, Minimal, TerminalPowerUser, EditorFocus, and Monitoring with automatic backups.

⚡

4. Command Center & Git Workbench

󰍉

Command Palette (Ctrl+P)

Fuzzy-search across all internal commands, toggle views, jump to pinned folders, reload configuration, or launch workspace tasks with a floating modal and acronym search.



Git Workbench (g / Ctrl+G)

Inspect repository status, branch tracking, staged vs. unstaged diffs, and recent commit history without switching windows. Stage files with s directly from the overlay.

🔌

Wasm Plugin Center (Ctrl+Shift+X)

Discover, install, enable, disable, and configure sandboxed WebAssembly extensions with SHA-256 integrity verification, permission enforcement, and hot reloading.
