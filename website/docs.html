Installation Methods

TermExplorer requires Linux with a 24-bit Truecolor terminal emulator. Install using your preferred package management method:

Option 1: Automated Shell Script (Recommended)

$ curl -sSL https://raw.githubusercontent.com/jyothiprajith1323/TermExplorer/master/install.sh | bash

Option 2: From Source via Cargo

$ cargo install --git https://github.com/jyothiprajith1323/TermExplorer.git

Option 3: Arch Linux (AUR)

$ yay -S termexplorer-bin

Configuration File (`config.toml`)

TermExplorer reads its configuration from ~/.config/termexplorer/config.toml. All settings can be adjusted directly in this file or through the Interactive Settings Studio (F10).

~/.config/termexplorer/config.toml (Standardized Defaults) ● Verified Valid
# TermExplorer v1.1.0 Developer Workstation Configuration [theme] name = "catppuccin_mocha" transparent_background = false [layout] explorer_ratio = 0.25 # Standardized 25% Explorer preview_ratio = 0.75 # Standardized 75% Preview terminal_height_percent = 15 # Compact 15% drawer (~6 rows) show_terminal = false # Hidden by default on launch show_sidebar = false # Zero screen space wasted on permanent sidebars show_preview = true show_hidden = false confirm_delete = true [terminal] default_height_percent = 22 # Compact drawer (~6-8 terminal rows) max_scrollback_lines = 10000 [editor] tab_size = 4 auto_pairing = true word_completion = true line_numbers = true [preview] max_file_size_mb = 20 image_rendering = "halfblock" # 24-bit Truecolor half-block RGB enable_video_thumbnails = true

Workstation Profiles & Themes

Switch instantly between pre-configured workspace profiles via F10 → Profiles:

Developer Profile

Standardized 25/75 workspace split with open bottom terminal and multi-format preview active.

Minimal Profile

Pure single-focus file management with hidden terminal and monitor for maximum tree view.

TerminalPowerUser Profile

Expanded 50% bottom terminal for intense shell, compilation, and command-line automation.
