Install · configure · explore

Get up and running on Linux.

Choose the installation route that matches your distribution. Packages are produced by the tagged release pipeline; verify that the asset exists on the Releases page before running an install command.

01 / Installation

Pick your package manager.

Use the package built for your distribution. For Debian-family systems, APT can install a downloaded local .deb package and resolve its declared dependencies.

◈ Debian / Ubuntu / Linux Mint

Format: .debArch: x86_64Local Package

Download the release .deb package and install with APT. APT resolves libc and shared runtime dependencies automatically.

Install 
sudo apt install ./termexplorer_1.1.0~rc2_amd64.deb
Remove 
sudo apt remove termexplorer

◉ Arch Linux / EndeavourOS / Manjaro

Format: PKGBUILDArch: x86_64In-Tree Recipe

Build the source or binary PKGBUILD locally with makepkg. In-tree recipes are in packaging/aur/; AUR publication is maintained separately.

Build & Install 
git clone https://github.com/jyothiprajith1323/TermExplorer.git
cd TermExplorer/packaging/aur
makepkg -si
Remove 
sudo pacman -R termexplorer

◒ Fedora / RHEL / Rocky / Alma

Format: .rpmArch: x86_64Local Package

Download the release .rpm package and install with DNF. Installs binary, manpage, desktop entry, icon and completions.

Install 
sudo dnf install ./termexplorer-1.1.0~rc2-1.x86_64.rpm
Remove 
sudo dnf remove termexplorer

◍ openSUSE

Format: .rpmArch: x86_64Local Package

Download the release .rpm package and install with Zypper. Compatible with openSUSE Leap and Tumbleweed.

Install 
sudo zypper install ./termexplorer-1.1.0~rc2-1.x86_64.rpm
Remove 
sudo zypper remove termexplorer

▤ Portable Linux archive

Format: .tar.gzArch: x86_64Self-Contained

Extract the release archive and run the included installer or place the standalone binary in your ~/.local/bin directory.

Install 
tar -xzf termexplorer-v1.1.0-rc2-linux-x86_64.tar.gz
cd termexplorer-v1.1.0-rc2-linux-x86_64
./install.sh
Remove 
./uninstall.sh

⌘ Build from source

Format: CargoArch: PortableSource Build

Build from source using Rust stable. Produces an optimized, LTO-enabled binary directly in your local target directory.

Compile & Install 
git clone https://github.com/jyothiprajith1323/TermExplorer.git
cd TermExplorer
cargo build --locked --release
install -Dm755 target/release/termexplorer ~/.local/bin/termexplorer
Remove 
rm -f ~/.local/bin/termexplorer
Package availability & repository status: The current public release is v1.1.0-rc2. Packages (.deb, .rpm, portable .tar.gz) are distributed directly as release assets. Local package installation (e.g. apt install ./package.deb) is the supported distribution method; signed APT and RPM hosted repository metadata scripts are provided in the repository for maintainers, while public hosted repos await dedicated signing infrastructure.
Additional Linux Distribution Evaluations:
  • NixOS: Flake recipe available at packaging/nix/flake.nix for declarative Nix environments.
  • Alpine Linux (musl): Evaluated for static compilation (x86_64-unknown-linux-musl). Standard glibc release binaries require gcompat.
  • Flatpak / AppImage: Evaluated; TermExplorer's embedded PTY terminal drawer requires unconfined host access (/dev/ptmx and host shell execution), making native packages preferred over container sandboxes.

02 / Runtime dependencies

Core application first. Optional tools when needed.

03 / First launch

Start with a project folder.

Launch the binary from a terminal, open a workspace and navigate with the application's keyboard controls. The terminal emulator provides the actual font and terminal protocol capabilities; TermExplorer can only use what the host terminal supports.

QUICK STARTLINUX SHELL
# Launch the workstation
$ termexplorer
# Or open a specific project
$ termexplorer ~/Projects/my-project
04 / Navigation

Keyboard-first by design.

Shortcut assignments can vary with application configuration. Use the in-app help and the current keybinding reference as the source of truth.

AreaCommon actionReference
Command PaletteFind and invoke application actions.Ctrl+Shift+P where configured.
SettingsOpen preferences.F10 in the documented default configuration.
TerminalToggle the terminal drawer.Ctrl+T in the documented configuration.
HelpOpen shortcut reference.F1 in the documented configuration.

Confirm bindings in docs/KEYBINDINGS.md before relying on them in customized profiles.
