Installation

TermExplorer requires a stable Rust toolchain (1.80+) or can be installed directly from pre-built binary releases.

Option 1: From Source via Cargo (Recommended)

$ cargo install --git https://github.com/jyothiprajith1323/TermExplorer.git

Option 2: Build Locally

$ git clone https://github.com/jyothiprajith1323/TermExplorer.git && cd TermExplorer && cargo build --release

The compiled binary will be placed at target/release/termexplorer. Move it into your $PATH (e.g. ~/.local/bin).

Keybinding Cheatsheet

TermExplorer uses Vim-inspired keybindings for ergonomic navigation with zero mouse dependency:

Shortcut Context Action Description
Tab Global Cycle focus between active panels (Sidebar → Explorer → Terminal → Monitor)
Shift+Tab Global Cycle focus backwards through active panels
Ctrl+Shift+P / P Global Open the fuzzy-search Command Palette
F1 Global Open the First-Launch Onboarding Wizard
F7 Global Toggle Dual-Pane side-by-side file explorer view
F10 Global Open the Interactive Settings Studio
` (Backtick) Global Toggle integrated PTY terminal drawer
m Global Toggle live system resource monitor panel
↓ / j Explorer Move selection down in directory
↑ / k Explorer Move selection up in directory
→ / Enter / l Explorer Navigate into selected directory (or preview file)
← / Backspace / h Explorer Navigate out to parent directory
/ Explorer Start live fuzzy filename filter
. Explorer Toggle display of hidden (dot) files
s Explorer Cycle sorting criteria (Name, Size, Modified Date, Extension)
a Explorer Create a new file in current directory
A Explorer Create a new directory in current directory
r Explorer Rename selected file or directory
d Explorer Move selected item to FreeDesktop Trash
D Explorer Permanently delete selected item (with confirmation)
c Explorer Copy item (or copy to opposing pane in Dual-Pane mode)
m Dual-Pane Move item to opposing pane
[ / ] Preview Switch preview tabs ([Preview], [Info], [Hex], [Actions])
g Global Open Git status and commit history overlay panel
Ctrl+S Editor Save current buffer to disk
Esc Editor / Modal Exit editor, dismiss overlay, or return to File Explorer
q Global Exit TermExplorer safely (restores terminal state)

Configuration File

TermExplorer reads its configuration from ~/.config/termexplorer/config.toml. If missing, it generates a well-documented default file automatically.

~/.config/termexplorer/config.toml
# TermExplorer Configuration File [theme] name = "catppuccin_mocha" transparent_background = true [general] sidebar_width = 20 preview_width = 45 show_hidden = false show_monitor = false dual_pane = false confirm_delete = true [editor] tab_size = 4 auto_pairing = true word_completion = true line_numbers = true [preview] max_file_size_mb = 10 image_rendering = "halfblock" enable_video_thumbnails = true

Profiles & Themes

TermExplorer includes 6 pre-configured layout profiles accessible via F10 → Profiles:

  • Developer: 35% preview width, terminal open at 35% height, system monitor visible.
  • Minimal: Hidden sidebar, hidden terminal and monitor, maximizing the file explorer area.
  • TerminalPowerUser: Expanded 50% bottom terminal for heavy CLI workflows.
  • EditorFocus: Full focus on source code buffer and preview.
  • Monitoring: System monitor pinned with high-frequency CPU/process telemetry.
  • Default: Balanced 4-panel developer environment.

Optional Linux CLI Utilities

To unlock advanced multimedia previews, install the following packages using apt:

$ sudo apt install -y ffmpeg poppler-utils gio trash-cli
