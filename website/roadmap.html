Development Milestones & Trajectory

Product Roadmap

TermExplorer is engineered for longevity and rock-solid reliability. Here is our transparent development trajectory.

v1.1.0 — The Developer Workstation

Release Candidate 1
Current Release Candidate

The milestone transforming TermExplorer into an integrated developer workstation:

  • Two-Column Workstation: Standardized 25% Explorer / 75% Preview with on-the-fly resizing (Ctrl+Right / Ctrl+Left up to 85%).
  • Integrated Linux PTY: Embedded terminal drawer (Ctrl+T) with maximize (Alt+F6) and resize ({ / }).
  • Keyboard Shortcuts Matrix: Redesigned workstation reference modal (F1 / ?) with categorized tabs.
  • Settings Studio: Interactive 14-category configuration center (F10) with atomic backups.
  • Catppuccin Ecosystem: Official Mocha default, Macchiato, Frappé, Latte, and transparent background inheritance.
  • WASM Plugins: Sandboxed extension runtime powered by wasmi with SHA-256 integrity verification.

v1.1.x — Integration & Data Safety Stabilization

In Active Engineering
Priority P0

Rigorously stabilizing core workflows and ensuring bulletproof data safety:

  • End-to-End Workflow Testing: Seamless development flow across Rust, Python, C/C++, Java, and Go projects without state loss.
  • Data Safety & Reliability: Safe file deletion, FreeDesktop trash integration, atomic file saving, and unsaved-change protection.
  • Filesystem Watcher: Instant external file modification detection and live buffer reload prompts.
  • CI Automation: Multi-architecture automated test matrix (x86_64 and ARM64 Linux).

v1.2.0 — Project Intelligence & Unified Search

Strategic Horizon
Planned

Three flagship capabilities reserved for the v1.2 milestone:

  • 1. Project Intelligence: Automatically recognizes Cargo.toml, pyproject.toml, Makefile, etc., and provides contextual quick-action commands (build, test, format, clippy).
  • 2. Workspace Session Manager: Save and restore entire multi-window development sessions, including open buffers, terminal scrollback, and cursor positions.
  • 3. Advanced Unified Search Engine: Search filenames, file contents (ripgrep-grade), AST symbols, and git commits through one unified high-speed interface.
