Development Milestones & Vision

Product Roadmap

TermExplorer is built for the long term. Here is our transparent development trajectory.

v0.1.0 — Foundation & Universal Previews

Shipped

The initial release establishing the complete developer terminal environment:

  • Universal 12+ format preview engine with 4 inspector tabs ([Preview], [Info], [Hex], [Actions]).
  • Dual-pane file management (F7) with FreeDesktop Trash integration.
  • Interactive Settings Studio (F10) with 15 sections and keybinding conflict detector.
  • 12 built-in themes with transparent terminal background inheritance.
  • Embedded interactive PTY terminal drawer and live system resource monitor.
  • Fuzzy-search command palette (Ctrl+Shift+P) and Git status dashboard (g).

v0.2.0 — Kitty Graphics & LSP Language Server

In Active Development

Expanding terminal graphics and intelligent code navigation:

  • Native Kitty graphics protocol & Sixel protocol passthrough for ultra-high-resolution image rendering.
  • Embedded Language Server Protocol (LSP) client support for go-to-definition and inline diagnostics.
  • Remote SSH / SFTP virtual filesystem integration for browsing remote servers seamlessly.
  • Split terminal tabs and multiple PTY multiplexing.

v0.3.0 — WebAssembly Plugins & Cloud Sync

Planned

Extensibility and ecosystem tooling:

  • Wasm-based plugin sandbox enabling third-party file previews, custom commands, and linters.
  • Encrypted dotfiles and configuration sync across developer workstations.
  • Collaborative terminal pair-programming sessions with zero latency.
