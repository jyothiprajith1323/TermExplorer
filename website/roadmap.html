Development Milestones & Trajectory

Product Roadmap

TermExplorer is engineered for longevity and rock-solid reliability. Here is our transparent development trajectory.

v1.1.0-RC2 — Universal Preview & Unified Search Engine

Delivered & 100% CI Verified (Sprint 3)
Current Release Candidate

The milestone delivering universal inspection, media decoding, structured data navigation, and workspace search:

  • Universal Preview Subsystem: Dedicated 4-tab Inspector ([Preview], [Info], [Metadata], [Actions]) with pure-Rust magic bytes detection.
  • Unified Search Engine: Sub-millisecond fuzzy filename discovery (/ or Ctrl+F) and ripgrep-grade full-text regex grep (Ctrl+Shift+F) with persistent history.
  • Vector & Raster Graphics: In-process SVG rasterization (resvg), PNG/JPEG/WebP/GIF/BMP rendering via 24-bit Truecolor half-blocks (▀/▄) with zoom and pan.
  • Structured Data & Database: Expandable JSON/YAML tree viewer, CSV/TSV auto-delimiter tables, and read-only SQLite schema/data inspector.
  • Media & Documents: Video multi-frame extraction via FFmpeg, audio metadata/cover art via Lofty, and pure-Rust PDF catalog parser with page stepping.
  • Virtual Archive & Hex: Traversal-safe ZIP/TAR/TAR.GZ virtual directory browsing and 16-byte memory hex viewer with pattern search.

v1.1.0-RC1 — Core Systems & Rope Editor (Delivered)

Delivered (Sprints 1 & 2)
Verified

Rock-solid core systems, asynchronous execution, and advanced editing foundation:

  • Two-Column Workstation: Standardized 25% Explorer / 75% Preview with on-the-fly resizing (Ctrl+Right / Ctrl+Left up to 85%).
  • Advanced Rope Editor: ropey data structure, transactional delta undo/redo (300 levels), and multi-cursor editing.
  • Data Safety & FreeDesktop Trash: Atomic file saving with POSIX flushes, FreeDesktop trash, and unsaved recovery snapshots.
  • 4-Layer Hybrid Autocomplete: Viewport buffer words, symbol indexer (<26 ms), language snippets, and LSP client.
  • Integrated Linux PTY: Embedded terminal drawer (Ctrl+T / `) with maximize (Alt+F6).

v1.2.0 — Project Intelligence & Cloud Sync

Sprint 4 Horizon
Planned

Flagship workstation workflow enhancements for the upcoming v1.2 milestone:

  • 1. Project Intelligence: Contextual build, test, format, and lint runners for Cargo, Poetry, NPM, and Go workspaces.
  • 2. Workspace Session Manager: Save and restore entire multi-window development sessions, including open buffers, terminal scrollback, and cursor positions.
  • 3. Native Packaging & Distribution: Standalone static Linux binaries, AppImage, Snap, and Arch AUR packages.
